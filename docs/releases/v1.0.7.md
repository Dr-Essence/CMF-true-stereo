### A small fix and an up-to-date README
- `stereoctl off` in stereo no longer tells you to reboot after `stereoctl channels mono`: Mono has switched at once since v0.9.4.
- The README now says exactly what this was tested on (CMF Phone 1, Nothing OS 4.1 **Tetris-B4.1-260615-1652-EEA**, Android 16) and what happens on other regions (Global, India: untested; the module refuses Stereo and stays in Mono if the audio files differ). Its *Risks* and *Safety and recovery* sections describe the protection as it is today.

Nothing changes in the sound.

Update from Magisk's **Update** button and reboot. Your settings are kept.

### Install
Flash in Magisk / KernelSU / APatch, reboot. CMF Phone 1 (A015) only; on other phones it installs and does nothing.

> **Before you use stereo:** stereo turns off Awinic's speaker protection for media (calls keep it); the module's own protection stands in. Use Mono for loud listening. If the phone fails to boot twice with stereo on, the module switches itself back to Mono.

Companion app: [CMF-true-stereo-manager](https://github.com/Dr-Essence/CMF-true-stereo-manager/releases/latest)
