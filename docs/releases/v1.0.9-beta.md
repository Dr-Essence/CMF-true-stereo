### Marked as a beta
CMF true stereo is still being tested, and its versions now say so: **beta** from this release on. Nothing in the module changed since v1.0.8.

Installs straight over v1.0.8 from Magisk, KernelSU or APatch (Magisk offers it as an update); no reboot problems, settings kept.

### Instruction manual (early beta)
`CMF-True-Stereo-Manual.pdf` below is the full instruction manual: every command, setting, safety net and fix of the module. It is an early beta, still being written.

### Install
Flash in Magisk / KernelSU / APatch, reboot. CMF Phone 1 (A015) only; on other phones it installs and does nothing.

> **Before you use stereo:** stereo turns off Awinic's speaker protection for media (calls keep it); the module's own protection stands in. Use Mono for loud listening. If the phone fails to boot twice with stereo on, the module switches itself back to Mono.

### Companion app
**[CMF-true-stereo-manager](https://github.com/Dr-Essence/CMF-true-stereo-manager/releases/latest)**: switch Mono and Stereo and set the levels from an app. Two editions: **CMF Stereo** (everyday) and **CMF Stereo Pro** (developer tools).
