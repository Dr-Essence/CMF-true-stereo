### Marked as a beta
CMF true stereo is still being tested, and its versions now say so: **beta** from this release on. Nothing in the module changed since v1.0.8.

Installs straight over v1.0.8 from Magisk, KernelSU or APatch (Magisk offers it as an update); no reboot problems, settings kept.
